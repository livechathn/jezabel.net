raspberry pi swap

memory expansion for constrained systems

by default, raspberry pi os doesn't configure swap space. this leaves your system vulnerable to oom (out of memory) kills when ram fills up. especially critical when running ollama models, databases, or multiple services simultaneously.

this guide configures a 2gb swap file with optimized swappiness settings to extend usable memory while protecting sd card longevity.

/// the problem

raspberry pi with 4gb ram runs out of memory when serving multiple ai models, web services, and background processes. without swap, the kernel oom-killer terminates processes randomly, causing service crashes and data loss. 

$ free -h
               total        used        free      shared  buff/cache   available
Mem:           3.7Gi       538Mi       2.1Gi       5.4Mi       1.2Gi       3.2Gi
Swap:             0B          0B          0B    ← NO SWAP CONFIGURED

/// the solution

configure swap space to extend available memory. optimized swappiness prevents excessive sd card writes while providing emergency memory overflow capacity.

  1. create 2gb swap file

    allocate 2gb of disk space for swap. uses fallocate for instant allocation.

    sudo fallocate -l 2G /swapfile
  2. set secure permissions

    restrict swap file access to root only. critical security step.

    sudo chmod 600 /swapfile
  3. format as swap

    mark file as swap space in the filesystem.

    sudo mkswap /swapfile
  4. activate swap

    enable swap immediately without reboot.

    sudo swapon /swapfile
  5. verify activation

    confirm swap is active and available.

    free -h 
                   total        used        free      shared  buff/cache   available
Mem:           3.7Gi       555Mi       2.1Gi       5.4Mi       1.2Gi       3.1Gi
Swap:          2.0Gi          0B       2.0Gi    ← SWAP ACTIVE
  6. make permanent

    ensure swap persists across reboots by editing fstab.

    echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
  7. optimize swappiness

    set swappiness to 10 (default is 60). lower value = less aggressive swapping.

    sudo sysctl vm.swappiness=10
  8. make swappiness permanent

    persist swappiness setting across reboots.

    echo 'vm.swappiness=10' | sudo tee -a /etc/sysctl.conf
  9. verify swappiness

    confirm setting is applied.

    cat /proc/sys/vm/swappiness 
    10

/// understanding swappiness

what is swappiness?

swappiness controls kernel's preference for swapping vs keeping data in ram. value range: 0-100.

swappiness values:
  • swappiness=0 → avoid swapping unless absolutely necessary
  • swappiness=10 → minimal swapping, prefer ram (recommended for pi)
  • swappiness=60 → ubuntu default, moderate swapping
  • swappiness=100 → aggressive swapping, prefer swap

why swappiness=10 for raspberry pi?

sd cards have limited write cycles. default swappiness=60 causes frequent writes, degrading card lifespan. swappiness=10 only swaps when ram is genuinely full, reducing writes by ~80%.

critical for sd card longevity: without optimized swappiness, constant swap writes can kill sd cards in months. swappiness=10 extends lifespan to years while still providing oom protection.

/// disk space check

before creating swap, verify sufficient disk space. swap file requires contiguous space.

df -h / 
Filesystem      Size  Used Avail Use% Mounted on
/dev/mmcblk0p2   57G   17G   38G  31% /    ← 38GB FREE, SUFFICIENT
minimum requirements: ensure at least 3gb free space beyond swap size for system operations. for 2gb swap, need 5gb+ total free.

/// technical notes

why fallocate over dd? fallocate is instant, dd takes minutes. both create valid swap files, but fallocate is preferred for speed and efficiency.
swap size recommendations:
  • 4gb ram → 2gb swap (what we configured)
  • 8gb ram → 2-4gb swap
  • 16gb+ ram → 4gb swap or less
swap is not ram replacement: swap is 10-100x slower than ram. it prevents crashes but doesn't improve performance. if constantly using swap, upgrade ram instead.

/// troubleshooting

swap not activating

# check file permissions ls -l /swapfile # should show: -rw------- 1 root root # if not, run: sudo chmod 600 /swapfile

disk full error

# check available space df -h / # if insufficient, reduce swap size or clean disk

remove swap

# disable swap sudo swapoff /swapfile # remove file sudo rm /swapfile # remove from fstab sudo nano /etc/fstab # delete swap line
