¿Por Qué argparse y @classmethod?

Cuando pasas de scripts simples a herramientas profesionales, necesitas:

1. argparse: Convierte tu script en una CLI tool que otros pueden usar sin editar código. Validación automática, ayuda con --help, y aspecto profesional.

2. @classmethod: Múltiples "constructores" para el mismo objeto. Cargar desde JSON, desde variables de entorno, desde presets... todo sin duplicar código.

Filosofía Lempyrλ: Código que se construye como LEGO - piezas pequeñas, reutilizables, que se pueden combinar de formas infinitas.
